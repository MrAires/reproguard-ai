# 2-Minute ReproGuard AI Demo Script

## 0:00-0:15 — Problem

"Research reproducibility information is scattered across the paper, citations, source repositories, and environment files. ReproGuard AI performs an evidence-first audit without pretending to decide whether a paper is true or good."

## 0:15-0:35 — Upload

Upload a paper or select the bundled demo. Show the extracted title, page count, DOI count, repository count, and RCI.

## 0:35-0:55 — Citation integrity

Open **Citations**. Explain that DOI identifiers are resolved against Crossref and OpenAlex, and disagreements or unavailable services remain visible as uncertainty.

## 0:55-1:20 — Reproducibility evidence

Open **Reproducibility**. Expand random seed, hyperparameters, metrics, and hardware. Show the exact evidence snippet behind each detection.

## 1:20-1:40 — Repository audit

Open **Repositories**. Show README, license, dependency, Docker, tests, source-layout, and CI signals.

## 1:40-1:55 — Evidence graph and agent trace

Show how the paper is connected to verified citations, repositories, and documentation signals. Then show the Plan/Act/Observe/Evaluate/Replan trace.

## 1:55-2:00 — Close

"The next research phase is to benchmark these automated findings against a manually annotated ReproAudit dataset and compare rule-based, LLM, and hybrid agentic approaches."
